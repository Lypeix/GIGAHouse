## What is GIGAHouse?

GIGAHouse is a massive project, which will cover the following features:
1. Item information
2. Source Facility tracking
3. Destination Facility tracking
4. Quantity of items
5. Departure times
6. Arrival times
7. Operators
8. Movement status
9. SKU tracking
10. Optional notes

## What technology stack will GIGAHouse use?

As of now, the planned tech stack is as follows:
1. Python
2. FastAPI
3. SQLAlchemy
4. PostgreSQL
5. Docker
6. GitHub Actions
7. Pydantic
8. Alembic
9. Pytest
